# 1. 실행환경 준비 방법
1. 저장소를 clone 한 후 cd week04를 입력해 'week04' 디렉토리로 이동을 합니다
2. python -m venv venv를 입력해 가상환경을 생성하고 .\venv\Scripts\activate를 입력해 가상환경을 활성화 합니다

# 2. 필요한 라이브러리 설치 방법
가상환경이 활성화 된 상태에서 pip install -r requirements.txt를 입력해 프로젝트에 필요한 라이브러리를 설치해 동일한 의존성 환경을 만듭니다.

# 3. 환경설정 준비 방법
환경변수 템플릿 파일(.env.example)의 내용을 복사하여 .env 파일을 생성한 뒤, 개인 설정값을 작성합니다.

# 4. 프로그램 실행 방법
1. python config_demo.py : 환경변수가 정상적으로 로드되는지, 민감 정보(비밀번호)가 마스킹 처리되어 출력되는지 확인합니다.
2. python memo_v2.py : 지정한 파일 경로로 메모를 불러오고 저장하는 프로그램을 실행하는지 확인합니다.
